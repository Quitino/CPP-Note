# CPP-Note

C++ 学习笔记。

在线阅读：**[https://Quitino.github.io/CPP-Note/](https://Quitino.github.io/CPP-Note/)**

## 本地预览

```bash
bundle install
bundle exec jekyll serve --source docs
# 浏览器访问 http://localhost:4000/CPP-Note/
```

## GitHub Pages 部署

在仓库 Settings → Pages 中，将 Source 设置为：

- Branch: `master`
- Folder: `/docs`
